# crabx's logo and site at crabx.kixel.me

## Goal

crabx has a logo and a one-page site at https://crabx.kixel.me that explains it, serves
`install.sh` and `install.ps1`, and is the only domain crabx's docs and scripts name.
This site is the root quest's docs page. Non-goals: a multi-page docs site, promotion,
which the site's PR adds as a follow-up for the maintainer, and any change to crabx's CLI.

## Plan

Decided with the maintainer on 2026-11-23, in /quest-plan:

- ✅ Logo and site, with crabx.kixel.me the canonical domain, and the site standing in
  for the root quest's docs page. Rejected: a site plus a separate docs page; drop.
- ✅ crabx.kixel.me rather than crabx.kixel.ai: like kixel-ai/token-max at max.kixel.me,
  crabx is the maintainer's personal project, which kixel.me lists.
- ✅ The header copies token-max's (`site/public/index.html` in kixel-ai/token-max):
  at the top right, a round avatar linking to https://kixel.me, then icon links to GitHub
  (this repository), X (https://x.com/kixelated), and Discord (https://discord.moq.dev).
  The icons are Simple Icons (CC0), inlined so the page loads nothing from another origin.
